## Sissejuhatus-Erialasse---Veebilehe-projekt

Tere!

Projekt poiss saab olema Minecrafti fännileht, mis koosneb kolmest osast: pealeht ehk landing page, 1. vaheleht, mis on satiirilises võtmes tutvustus, kuidas vallutada Mincrafti serveri maailm, ja 2. vaheleht, mis aitab mainitud maailmas vahemaid arvutada kasuliku kalkulaatoriga. Rühm on kolmeliikmeline ning igaüks saab õppida veebiarendust oma leheküljega. Lõpuks tuleb kokku ühtne veebisait.
