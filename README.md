# Sissejuhatus-Erialasse---Veebilehe-projekt

Minecrafti fännileht koosneb kolmest osast: pealeht ehk _landing page_, 1. vaheleht, mis on satiirilises võtmes tutvustus, kuidas vallutada Mincrafti serveri maailm, ja 2. vaheleht, mis aitab mainitud maailmas vahemaid arvutada kasuliku kalkulaatoriga. Rühm on kolmeliikmeline ning igaüks saab õppida veebiarendust oma leheküljega. Lõpuks tuleb kokku ühtne veebisait.
